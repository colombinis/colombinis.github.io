# Glosario

## Terminos del Proyecto

| Termino | Definicion |
|---------|-----------|
| DESIGN.md | Archivo de especificacion de diseno de Google. Define tokens visuales (colores, tipografia, componentes) en formato YAML+Markdown. |
| Token de diseno | Valor unico que representa una decision de diseno (color, fuente, espaciado). Ej: `colors.primary = #1A1A2E` |
| DoD | Definition of Done — lista de condiciones que un issue debe cumplir para considerarse completo. |
| WCAG | Web Content Accessibility Guidelines — estandar de accesibilidad web. Nivel AA es el minimo recomendado. |
| CTA | Call to Action — boton o elemento que invita al usuario a realizar una accion (contactar, comprar, etc.) |
| Hero | Seccion superior de una landing page, visible sin hacer scroll. |
| Mobile-first | Estrategia de diseno donde se disena primero para pantallas chicas y luego se adapta a pantallas grandes. |
| Lighthouse | Herramienta de Google que audita performance, accesibilidad, SEO y buenas practicas de un sitio. |

## Colores de Marca

| Token | Hex | Uso |
|-------|-----|-----|
| primary | #1A1A2E | Fondos oscuros, headlines, CTA section |
| secondary | #555555 | Texto corporal secundario |
| tertiary | #0A7CFF | Unico color de interaccion (hover, links) |
| neutral | #FAFAFA | Fondo general de pagina |
| surface | #FFFFFF | Fondos de cards y formularios |
| muted | #888888 | Texto secundario de bajo contraste |
| whatsapp | #25D366 | Exclusivo para boton de WhatsApp |
