Analogía UJ · CON · PRI

Es como planear un viaje en auto.

UJ (User Journey) = el mapa y las paradas: quién viaja (personas), qué ruta toma (homepage → servicio → contacto), qué señales ve (CTAs). Sin mapa no sabés si llegás.

CON (Conversión y tráfico) = contar autos en la ruta: cuántos entran (visitas TOFU), cuántos paran a preguntar (leads MOFU), cuántos compran pasaje (clientes BOFU). También calculás cuánto combustible necesitás para llegar al destino (breakeven).

PRI (Modelo de precios) = cuánto cuesta cada servicio de transporte: cuántas horas consume cada tipo de auto (horas estimadas × tarifa $22k/h), cuál es el precio del pasaje, y si ganás o perdés con cada ruta.

Regla: UJ define el destino → CON mide el tráfico → PRI calcula la rentabilidad. Si cambian las horas o precios en PRI, los cálculos de CON se recalculan solos.

Saber más: qué hace cada variable
  • Tarifa USD + Tipo de cambio → definen el costo por hora interno (ARS/h). Es la variable madre: todo margen depende de ella.
  • Tasa visita→lead (MOFU) → % de visitantes que clickean WhatsApp o envían form. Si baja a 1%, el tráfico necesario se duplica. Punto más sensible.
  • Tasa lead→cliente (BOFU) → % de leads que cierran proyecto. 20-30% típico en servicios B2B.
  • Ticket medio → ingreso promedio por cliente. CON-03 usaba 4M; con precios reales de PRI-03 ajustados baja a ~1.5M. Cambiar esto recalcula todos los escenarios.
  • Costo cash mensual → hosting + ads + herramientas. Breakeven "cash" = cubrir esto.
  • Horas objetivo/mes → cuántas horas querés facturar para "pagarte" tu tiempo. Breakeven "tiempo" = horas × tarifa ARS/h.

Cómo se conectan 3 fases → 1 flujo

UJ — Mapa del viaje

3 personas (Carlos: PyME sin web; Ana: WP roto; Lucas: reclutador). Cada persona recorre homepage → servicio → contacto (WhatsApp o formulario). 15/15 páginas con CTA claro (UJ-05). El funnel existe; falta trackearlo (CON-04).

CON — Tráfico y breakeven

Funnel TOFU/MOFU/BOFU. 3 escenarios recalculados en vivo según tus variables. El escenario A cubre cash desde mes 1; B es rentable con ads; C requiere equipo (subcontratación).

PRI — Costos y precios

Tarifa real (USD/h → ARS/h). Cada servicio tiene horas estimadas y precio ajustado. 3 tiers con margen negativo ya corregidos. El breakeven se valida comparando ingreso (CON) vs costo horas (PRI).

Saber más: cómo se calcula cada fila
  • Precio (ARS): valor que paga el cliente, definido en PRI-02 (ajustado en PRI-03). Editable: para testear descuentos o presupuestos reales.
  • Horas est.: rango estimado para completar el alcance. Editable: si una tarea real toma más horas, el costo sube.
  • Costo fijo (ARS): gastos directos del trabajo (dominios, plugins, pasarelas). Default 0. Se suma al costo por horas.
  • Costo @ARS/h: horas × tarifa ARS/h + costo fijo. Variable madre que conecta PRI con CON.
  • Margen min / max: (precio - costo) / precio. Si baja de 0%, el servicio pierde dinero.
  • Estado OK / NEGATIVO: indica si el rango cubre el costo con margen positivo.
