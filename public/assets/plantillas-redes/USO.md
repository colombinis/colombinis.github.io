# Reglas de uso de las plantillas

1. Abrir el `.html` en el navegador.
2. Reemplazar textos y rutas de imagen (`src="..."`) por tus assets.
3. Mantener el CSS inline para exportar como imagen desde el navegador (Print/PDF o captura).
4. No cambiar la paleta ni las familias tipográficas.
5. Cada plantilla incluye comentarios `<!-- CAMBIAR: ... -->` indicando dónde editar.
