# Plantillas de redes — SACsi

## Uso

1. Abrir el `.html` en el navegador.
2. Reemplazar textos y rutas de imagen por tus assets.
3. Exportar como imagen con Print/PDF o captura de pantalla.

## Archivos

- `carrusel.html` — Slide 1:1 para carrusel de Instagram/LinkedIn.
- `reel-short.html` — Formato vertical 9:16 para Reel/Short/TikTok.
- `miniatura-youtube.html` — Formato 16:9 para thumbnails de YouTube.
- `cita.html` — Tarjeta 1:1 para citas y frases destacadas.
- `caso-exito.html` — Tarjeta 1:1 con portada + KPIs + CTA.
- `captura-tecnica.html` — Layout 16:9 para capturas de código/métricas.

## Reglas

- Mantener paleta `DESIGN.md`: primary `#1A1A2E`, tertiary `#0A7CFF`, whatsapp `#25D366`.
- No usar verde WhatsApp fuera del CTA.
- Tipografía del sistema; sin fuentes externas.
